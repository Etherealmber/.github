# Etherealmber · `.github`

This is the special **organization profile repository** for [Etherealmber](https://github.com/Etherealmber).

```
.github/
└── profile/
    └── README.md   ← the README rendered on https://github.com/Etherealmber
```

> **Note:** GitHub only renders `profile/README.md` on the organization profile.
> The root `README.md` you are reading now is just the repo's own landing page.

## Editing the profile

1. Edit [`profile/README.md`](profile/README.md)
2. Commit to `main`
3. Refresh <https://github.com/Etherealmber> — changes appear immediately (cached for a few minutes)
