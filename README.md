# Etherealmber · `.github`

The **organization profile repository** for [Etherealmber](https://github.com/Etherealmber).

```
.github/
└── profile/
    └── README.md   ← rendered on https://github.com/Etherealmber
```

> GitHub only renders `profile/README.md` on the organization profile.
> This root `README.md` is the repository's own landing page.

## Editing the profile

1. Edit [`profile/README.md`](profile/README.md)
2. Commit to `main`
3. Refresh <https://github.com/Etherealmber> — updates appear within a few minutes

The header points at the org avatar (`avatars.githubusercontent.com/u/318825377`), so changing the picture in **Organization settings → Profile picture** updates the profile too.
