# Etherealmber · `.github`

The **organization profile repository** for [Etherealmber](https://github.com/Etherealmber).

```
.github/
└── profile/
    └── README.md   ← rendered on https://github.com/Etherealmber
```

> GitHub only renders `profile/README.md` on the organization profile.
> This root `README.md` is just the repository's own landing page.

## Editing the profile

1. Edit [`profile/README.md`](profile/README.md)
2. Commit to `main`
3. Refresh <https://github.com/Etherealmber> — updates appear within a few minutes

The profile header points at the org avatar (`avatars.githubusercontent.com/u/318825377`), so changing the picture in **Organization settings → Profile picture** updates the README too.

## What Etherealmber is building

One connected system for Moroccan commerce:

| Product | Status |
|---|---|
| [**Atlas Commerce**](https://github.com/Etherealmber/atlas-commerce) — ERP / POS / invoicing core | target: end of 2026 |
| **Atlas Commerce for Android** — offline-first field app | target: end of 2026 |
| **Atlas Shop** — storefront reading live data from Atlas Commerce | during 2027 |
| **Support** — public help and request portal | during 2027 |
| **Complete, enhanced system** | before the end of 2027 |

Everything connects through the same Partner API and webhook layer, so products, stock, prices and customers are never duplicated across projects.
